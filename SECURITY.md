# Security Policy

UltraWide ChatGPT is a client-side browser userscript, not an official OpenAI integration or a proxy service. It stores local preferences via userscript storage and operates on ChatGPT's DOM.

## Report responsibly

For potential credential exposure, data disclosure, code injection, or another security-sensitive problem, **do not publish exploitable details or private conversation data in a public issue**. Use GitHub's **Report a vulnerability** / private reporting option if enabled for this repository. If unavailable, create an issue containing only a non-sensitive high-level summary and request a private reporting channel.

Ordinary layout bugs belong in [GitHub Issues](https://github.com/jsmlabs/ultrawide-chatgpt/issues).

## Privacy and verification boundaries

Diagnostic exports can contain page URLs, settings, browser information and runtime events. Review and redact before sharing. Repository syntax and Node regression tests do not prove the absence of security issues or guarantee future compatibility.

No guaranteed response or remediation time is established.
